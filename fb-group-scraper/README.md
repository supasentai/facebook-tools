### How to use Group Member Scraper

1. Navigate to the members page of target Facebook group:
   `https://www.facebook.com/groups/<group-id>/members`
2. Open **Developer Tools** (`F12`) -> **Console** tab.
3. Copy the entire contents of `fb-group-scraper/index.js`, paste it into the console, and press **Enter**.
4. The script will automatically scroll to load members, collect profile data, and trigger a `.csv` download when complete.
