### How to use Cancel Sent Requests

1. Open Facebook Friend Requests and view sent requests:
   `https://www.facebook.com/friends/requests` (Click **View sent requests** / **Xem lời mời đã gửi**).
2. Open **Developer Tools** (`F12`) -> **Console** tab.
3. Copy the entire contents of `fb-cancel-sent-requests/index.js`, paste it into the console, and press **Enter**.
